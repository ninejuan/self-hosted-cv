# Changelog

## v0.1.0 - 2026-04-26

Initial release with:

- Public CV website and NestJS API.
- Authenticated admin panel for CV content management.
- PostgreSQL persistence, Redis sessions and caching, and MinIO media storage.
- TOTP 2FA backend support.
- Media orphan cleanup scheduled job.
- Audit logging, CSRF protection, login throttling, and structured logs.
- Error boundaries, skeleton loading states, and toast notifications.
- Docker Compose deployment and GitHub Actions CI/release workflows.
